# Dishari Chemistry (দিশারী কেমিস্ট্রি) 🧪

> **ট্যাগলাইন:** “রসায়ন শিখি সহজভাবে, এগিয়ে যাই আত্মবিশ্বাসে”

**Dishari Chemistry** হলো বাংলাদেশের এসএসসি (SSC), এইচএসসি (HSC ১ম ও ২য় পত্র), এবং স্নাতক সম্মান (Honors) পর্যায়ের শিক্ষার্থীদের জন্য নির্মিত একটি সম্পূর্ণ বাংলা ফুল-স্ট্যাক রসায়ন লার্নিং প্ল্যাটফর্ম।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

1. **তিনটি একাডেমিক স্তর (SSC, HSC, Honors):**
   - **এসএসসি রসায়ন:** এনসিটিবি (NCTB) নবম-দশম শ্রেণির সম্পূর্ণ ৮টি অধ্যায়ভিত্তিক পাঠ ও কুইজ।
   - **এইচএসসি রসায়ন:** ১ম পত্র ও ২য় পত্রের পূর্ণাঙ্গ গুণগত রসায়ন, পর্যায়বৃত্ত ধর্ম, পরিবেশ রসায়ন, জৈব রসায়ন মেকানিজম ও পরিমাণগত গণনা।
   - **অনার্স রসায়ন:** উচ্চতর জৈব মেকানিজম, কোঅর্ডিনেশন কেমিস্ট্রি (CFT), মলিকুলার স্পেকট্রোস্কোপি (UV, IR, NMR), এবং কোয়ান্টাম রসায়ন।

2. **ইন্টারঅ্যাক্টিভ পর্যায় সারণি (Periodic Table):**
   - আধুনিক IUPAC স্বীকৃত **১১৮টি মৌলিক পদার্থের** পূর্ণ তথ্য।
   - বাংলা ও ইংরেজি নাম, প্রতীক, পারমাণবিক সংখ্যা, আপেক্ষিক পারমাণবিক ভর, ইলেকট্রন বিন্যাস, জারণ অবস্থা, দশা (কঠিন, তরল, গ্যাস), এবং বাস্তব শিল্প প্রয়োগ।
   - ক্যাটাগরি, পর্যায় ও গ্রুপ ভিত্তিক ফিল্টার ও লাইভ সার্চ।

3. **বিক্রিয়া লাইব্রেরি (Chemical Reactions Library):**
   - ৮টি প্রধান বিভাগের রাসায়নিক বিক্রিয়া: সংযোজন, বিযোজন, একক প্রতিস্থাপন, দ্বি-প্রতিস্থাপন, দহন, জারণ-বিজারণ, প্রশমন, এবং জৈব বিক্রিয়া (মার্কোনিকভ, অ্যালডল, ক্যানিজারো ইত্যাদি)।
   - সমতাকৃত সমীকরণ, প্রভাবক ও তাপমাত্রা-চাপের শর্ত, পর্যবেক্ষণ ও নিরাপত্তা সতর্কতা।

4. **ফর্মুলা ও লাইভ ক্যালকুলেশন সেন্টার:**
   - KaTeX রেন্ডারকৃত সুন্দর গাণিতিক সমীকরণ ও প্রতীকের একক ব্যাখ্যা।
   - ৫টি কার্যকরী লাইভ ক্যালকুলেটর:
     - মোলারিটি ($S = \frac{W \times 1000}{M \times V}$)
     - আদর্শ গ্যাস সূত্র ($PV = nRT$)
     - মোলের ধারণা ও কণা গণনা ($n = \frac{W}{M} = \frac{N}{N_A}$)
     - দ্রবণের লঘুকরণ ($V_1 S_1 = V_2 S_2$)
     - pH ও pOH গণনা ($pH = -\log[H^+]$)

5. **পরীক্ষা ও কুইজ ইঞ্জিন:**
   - সময় নিয়ন্ত্রিত অনলাইন পরীক্ষা (টাইমার ও ওয়ার্নিং)।
   - নেগেটিভ মার্কিং কনফিগারেশন।
   - সার্ভার-সাইড মূল্যায়ন ও ব্যাখ্যা সহ রেজাল্ট শিট।
   - ভুল উত্তর পর্যালোচনার সুযোগ।

6. **শিক্ষার্থী ড্যাশবোর্ড ও টুলস:**
   - সমাপ্ত পাঠের ট্র্যাকিং ও বুকমার্ক।
   - ব্যক্তিগত গোপনীয় পাঠ নোট (Private Student Notes)।
   - কুইজ হিস্ট্রি ও গড় নম্বর।
   - দুর্বল টপিক চিহ্নিতকরণ।

7. **অ্যাডমিন প্যানেল:**
   - কোর্স ও অধ্যায় ব্যবস্থাপনা।
   - লেসন রিচ-এডিটর (শিখনফল, সমীকরণ, উদাহরণ ও ড্রাফট/পাবলিশ মোড)।
   - প্রশ্ন ব্যাংক পরিচালনা।
   - শিক্ষার্থী ও রোল পারমিশন ম্যানেজমেন্ট।
   - শিক্ষার্থীদের রিপোর্টেড এরর ও অডিট লগ ট্র্যাকিং।

## 🛠️ প্রযুক্তিগত কাঠামো (Technology Stack)

- **Frontend & Backend:** Next.js (App Router) + TypeScript
- **Styling:** Tailwind CSS (Deep Blue `#0f172a` & Teal `#0d9488` থিম)
- **Math/Equation Rendering:** KaTeX
- **Database Architecture:** PostgreSQL Schema + Supabase RLS Policies (স্থানীয় ফাইল ব্যাকড পারসিস্টেন্স সহ)
- **Celebration Animations:** Canvas-Confetti

## 🚀 লোকাল সেটআপ নির্দেশিকা (Local Setup Instructions)

### ১. রিপোজিটরি ক্লোন ও ইনস্টল
```bash
git clone <repository_url>
cd dishari-chemistry
npm install
```

### ২. এনভায়রনমেন্ট ভেরিয়েবল কনফিগারেশন
`.env.example` ফাইলের অনুকরণে `.env.local` তৈরি করুন:
```env
GEMINI_API_KEY="your_api_key_if_applicable"
APP_URL="http://localhost:3000"
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু
```bash
npm run dev
```
ব্রাউজারে ভিজিট করুন: `http://localhost:3000`

### ৪. স্বয়ংক্রিয় টেস্ট রান
```bash
node --test tests/chemistry.test.ts
```
